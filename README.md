## 🚀 Cara Menjalankan Proyek

1. Clone repository
```bash
git clone https://github.com/LazyDaoist/ficportfolio.git
cd ficportfolio
```

2. Install dependencies
```bash
npm install
```

3. Jalankan development server
```bash
npm run dev
```

4. Buka [http://localhost:3000](http://localhost:3000)
